\# Дашборд: Аналитика косметологической компании (Fastboard)



\## О проекте

Дашборд разработан в рамках \*\*Конкурса дашбордов среди BI-аналитиков\*\* на BI-платформе \*\*Fastboard\*\* — российской системе визуального анализа данных.



\## Суть конкурса

Участникам давали \*\*реальный бизнес-кейс\*\* (набор живых данных) от \*\*косметологической компании\*\*. Задача — собрать \*\*понятный интерактивный дашборд\*\* на платформе Fastboard.



\## Для кого

Конкурс проводился как для \*\*практикующих аналитиков\*\*, так и для тех, кто прошёл \*\*обучающий курс\*\* по работе с платформой.



\## Ценность

\- Открытый разбор (\*\*«прожарка»\*\*) дашбордов от \*\*экспертов индустрии\*\*.

\- Сертификаты и призы.



\## Личный результат

🏆 \*\*Гран-при\*\* (выбор экспертов)
