\# Dashboard: Cosmetics Company Analytics (Fastboard)



\## About the project

The dashboard was created as part of the \*\*Dashboard Contest for BI Analysts\*\* on the \*\*Fastboard\*\* BI platform — a Russian visual data analysis system.



\## Contest overview

Participants were given a \*\*real business case\*\* (a set of live data) from a \*\*cosmetics company\*\*. The goal was to build a \*\*clear, interactive dashboard\*\* on the Fastboard platform.



\## Who it was for

The contest was open to both \*\*practicing analysts\*\* and those who had completed a \*\*training course\*\* on the platform.



\## Value

\- Open review (\*\*"roast"\*\*) of dashboards by \*\*industry experts\*\*.

\- Certificates and prizes.



\## Personal result

🏆 \*\*Grand Prix\*\* (experts' choice)
