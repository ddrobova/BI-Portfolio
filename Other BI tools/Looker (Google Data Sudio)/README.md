### [NYC Taxi Trips Analysis (Looker Studio)](httpsdatastudio.google.comreporting2e890b33-e923-4879-8421-828979df767c)

Project Personal portfolio project exploring the same real-world NYC taxi dataset, but built entirely within the Google Cloud ecosystem using Looker Studio.  
Dataset NYC taxi trips — a real-world dataset.  
Task Recreate the analytical experience in a cloud-native BI tool, focusing on interactive cross-filtering, dynamic user controls, and clean layout design.

What was done
- Data Preparation Connected and prepared the data source, ensuring correct data types for dates and aggregations.
- Interactive Controls Implemented a custom date range control and a Reset Filters button for seamless user navigation.
- Visualization Built a heatmap matrix (Trips by Day of Week and Hour), ranking tables (Districts by Volume and Avg Fare), and dynamic bar charts (Top 6 Peak Hours).
- UXUI Design Designed a clean, focused layout with clear KPI scorecards (Total Fare, Trips, AVG Distance) and consistent color palettes to highlight key insights.

Value Demonstrates adaptability across BI platforms (Power BI ↔ Looker Studio), understanding of cloud-based visualization tools, and the ability to build intuitive, self-service reporting interfaces.
