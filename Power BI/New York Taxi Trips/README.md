### NYC Taxi Trips Analysis (Power BI Portfolio Community)

**Project:** Personal portfolio project inspired by the Power BI Portfolio Community by a real-world dataset.  
**Task:** Build a complete report from scratch, from data transformation and modeling to interactive visualization, applying industry best practices.

**What was done:**
- **Data Modeling & Power Query:** transformed and modeled real-world data; built a custom Date table.
- **DAX:** created dynamic KPIs, calculated % of total, identified peak days and hours, applied conditional formatting.
- **Visualization:** built interactive maps (pick-up and drop-off using `.json` files), heatmaps, custom tooltips, and HTML visuals for polished text blocks.

**Value:** Hands-on experience with a real-world dataset, end-to-end report development, and a chance to compare the result with peers' work in the community.
